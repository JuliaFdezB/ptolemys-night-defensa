# Ptolemy's Night — Defensa del TFG

Presentación interactiva (web) para la defensa del Trabajo de Final de Grado
**"El impacto de la IA en el diseño y desarrollo de videojuegos: un caso de estudio a través de Ptolemy's Night"**, de Julia Fernández Bermejo (Universitat Jaume I).

## Ver la presentación
Abre `index.html` en el navegador (o, publicada en GitHub Pages, en la URL del repositorio).

## Controles
- **← → / espacio / clic** — navegar (con revelados por pasos)
- **S** — notas de orador
- **T** — temporizador (cuenta atrás de 10 min) · **R** reinicia
- **F** — pantalla completa

Hecho a medida en HTML/CSS/JS, sin dependencias externas.
